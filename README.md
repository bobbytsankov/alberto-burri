# Алберто Бури: цикли и техники

Учебна страница за циклите и техниките на Алберто Бури (НХА, катедра „Сценография“).

Страницата е статична: `index.html` и папка `img/`. Не се нуждае от сборка.

Публикуване през GitHub Pages: Settings → Pages → Source: „Deploy from a branch“, клон `main`, папка `/ (root)`.
